# Screen Annotation 사용 가이드

트레이에서 실행됩니다. **Ctrl+Shift+Space**를 누르면 모든 모니터가 정지되고 그 위에 판서합니다. 다시 누르면 꺼집니다.

## 키·마우스

| 입력 | 동작 |
| --- | --- |
| Ctrl+Shift+Space | 켜기(화면 정지 + 펜) / 끄기 |
| 좌클릭 드래그 | 현재 도구로 그리기 |
| 우클릭 | 팔레트 — 펜·형광펜: 색상 / 도형: 도형 종류 (끌어서 놓거나 짧게 클릭 후 선택) |
| 휠 | 굵기 (펜 1~40px, 형광펜 8~64px, 도형 1~16px) |
| Ctrl+휠 / Ctrl+0 | 커서 기준 확대 1~8× / 원래대로 |
| 가운데 버튼 드래그, Space+드래그 | 확대 상태에서 이동 |
| Tab | 펜 → 형광펜 → 도형 |
| Shift+Tab | 변형 — 펜: 일반 → 사라지는 펜 → 레이저 / 형광펜: 자유 → 직선 / 도형: 사각형 → 삼각형 → 원 → 원기둥 → 화살표 → 직선 |
| Shift+드래그 (도형) | 정사각형·정원·정삼각형, 화살표·직선 45° 스냅 |
| 펜 획 끝에서 0.5초 멈춤 | 직선·사각형·타원으로 자동 보정 (Ctrl+Z로 원래 획) |
| 1~9 | 색 바로 선택 (팔레트 순서) |
| T / 빈 곳 더블클릭 | 텍스트 입력 (Enter 줄바꿈, Ctrl+Enter 또는 바깥 클릭으로 확정, 글자 더블클릭으로 재편집) |
| E | 지우개 켜기/끄기. 클릭하면 그 자리, 드래그하면 지나간 객체 전부 삭제 |
| Ctrl+클릭 | 화면 요소(이미지·글자) 선택 |
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Ctrl+S / Ctrl+C | 정지 화면+판서 PNG 저장 / 클립보드 복사 |
| Esc | 진행 중 취소, 팔레트 닫기, 펜으로 복귀. 앱은 꺼지지 않음 |

## 색상 팔레트 (우클릭·숫자 키 순서)

| 번호 | 색 | 값 |
| --- | --- | --- |
| 1 | 빨강 | #FF3B30 |
| 2 | 주황 | #FF9500 |
| 3 | 노랑 | #FFCC00 |
| 4 | 초록 | #34C759 |
| 5 | 파랑 | #007AFF |
| 6 | 남색 | #3F51B5 |
| 7 | 보라 | #AF52DE |
| 8 | 흰색 | #FFFFFF |
| 9 | 검정 | #000000 |

색은 도구별로 기억합니다 (기본: 펜 빨강, 형광펜 노랑, 도형 빨강).

## 도형 팔레트

| 순서 | 도형 | 그리는 방법 | Shift |
| --- | --- | --- | --- |
| 1 | 사각형 | 대각선 드래그 | 정사각형 |
| 2 | 삼각형 | 드래그 상자에 맞춘 이등변삼각형 | 정삼각형 |
| 3 | 원 | 드래그 상자에 내접하는 타원 | 정원 |
| 4 | 원기둥 | 윗면 타원 + 옆선 + 아랫면 반타원(뒤는 점선) | 윗면 원형 |
| 5 | 화살표 | 시작 → 끝 | 45° 단위 |
| 6 | 직선 | 시작 → 끝 | 45° 단위 |

## 우측 툴바

켜진 동안 화면 오른쪽에 세로 툴바가 있습니다. 위에서부터 펜 · 사라지는 펜 · 레이저 · 형광펜 · 직선 형광펜 · 도형(클릭하면 6종 펼침) · 텍스트 · 지우개 / 색 9개 / 굵기 − + / Undo · Redo / 저장 · 복사 · 1× / 닫기. 마우스를 올리면 단축키가 보입니다. 우측 하단 HUD는 현재 도구·변형·굵기·색을 보여 줍니다.

## 사라지는 펜

펜에서 Shift+Tab 한 번(또는 툴바 두 번째 버튼). 손을 뗀 뒤 2.5초 유지되고 0.5초 동안 서서히 사라집니다. 연속으로 그린 획은 마지막 획 기준으로 함께 사라집니다. Undo 대상이 아니며, 저장 순간 보이는 획은 PNG에 포함됩니다.

## 저장 위치

- PNG: `사진\ScreenAnnotation\yyyyMMdd_HHmmss_모니터번호.png` (모니터별 1장)
- 설정: `%APPDATA%\ScreenAnnotation\settings.json`, 로그: `%LOCALAPPDATA%\ScreenAnnotation\logs`
- 저장하지 않은 판서는 끄면 사라집니다.

## 알아 둘 것

- **화면 공유**: Zoom·Teams 등에서 "특정 창만 공유"하면 판서가 보이지 않습니다. **"전체 화면 공유"**를 쓰세요.
- **전체 화면 독점 게임**은 지원 대상이 아닙니다 (캡처 실패 또는 오버레이가 위에 뜨지 않음).
- **관리자 권한으로 실행된 창** 위에서는 Ctrl+클릭 요소 인식이 이미지 분석만 됩니다.
- Ctrl+Shift+Space가 VS Code 등과 겹치면 트레이 아이콘 → 설정에서 단축키를 바꾸세요.
- 앱이 멈추면 워치독이 3초 안에 오버레이를 내리고 앱을 종료합니다. 화면이 잠기지 않습니다.
