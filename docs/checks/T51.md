# T51 — 끄기 확인창

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 판서 없음 → 즉시 끔 | 켜기 → 아무것도 안 그리고 Ctrl+Shift+Space → 확인창 없이 바로 꺼짐 | |
| 저장 | 획 하나 → Ctrl+Shift+Space → Enter → 사진\ScreenAnnotation에 PNG, 이후 꺼짐 | |
| 버리기 | 획 하나 → Ctrl+Shift+Space → N → 저장 없이 꺼짐 | |
| 계속 판서 | 획 하나 → Ctrl+Shift+Space → Esc → 확인창 닫히고 계속 그릴 수 있음, 기존 획 유지 | |
| 확인창 중 Ctrl+Shift+Space | 확인창이 뜬 상태에서 한 번 더 → 버리고 바로 꺼짐 | |
| 확인창 중 입력 무시 | 확인창이 뜬 상태에서 오버레이를 드래그·Tab·휠 → 아무 변화 없음 | |
| 커서 모니터 | 보조 모니터에 커서를 두고 끄기 → 확인창이 그 모니터 가운데 | |
