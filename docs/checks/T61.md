# T61 — 설치 프로그램·자동 시작

빌드: `build\make-installer.ps1 -Version 0.1.0` → `dist-installer\ScreenAnnotation-Setup-0.1.0.exe` (Inno Setup 6, `winget install --id JRSoftware.InnoSetup -e`).

## 게시 방식 결정

| 방식 | dist 크기 | 설치 요구 | 결정 |
| --- | --- | --- | --- |
| framework-dependent (`publish.ps1`) | 27.1 MB (Setup 6.3 MB) | .NET 8 Desktop Runtime x64 (설치 프로그램이 없으면 안내) | **채택** — 작고, 런타임은 Windows 11 업데이트에 흔히 포함 |
| self-contained 단일 파일 (`publish.ps1 -SelfContained`) | 190 MB (App 단일 exe 189.9 MB) | 없음 | 보류 — 런타임 미설치 PC가 많으면 전환 (`make-installer.ps1 -SelfContained`) |

측정 2026-10-15 (Release, win-x64): framework-dependent dist 27.1 MB → Setup 6.3 MB / self-contained 190.2 MB. 7배 차이라 framework-dependent 채택.

## 확인 (깨끗한 Windows 11)

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 설치 | Setup 실행 → Program Files\ScreenAnnotation, 시작 메뉴 항목, (선택) 바탕화면·자동 실행 | |
| .NET 안내 | 런타임 없는 PC에서 Setup → 안내 메시지 후 설치 계속, 런타임 설치 후 실행됨 | |
| 첫 실행 안내 | 처음 실행 시 단축키 안내 창, "다시 보지 않기" 체크 후 다음 실행에는 안 뜸 | |
| 자동 시작 | 작업에서 체크 → 재부팅 후 트레이에 떠 있음 (HKCU\...\Run "ScreenAnnotation") | |
| 제거 | 프로그램 제거 → `{app}` 폴더·시작 메뉴·Run 값 없음. `%APPDATA%\ScreenAnnotation`(설정)·`%LOCALAPPDATA%\ScreenAnnotation\logs`는 의도적으로 남김 | |
| 코드 서명 | `installer.iss`의 SignTool 주석 해제 + 인증서 등록 후 서명된 Setup인지 확인 | 미서명 (인증서 없음) |
