# T13 — 창 목록 스냅샷 확인

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 최소화 창 제외 | 메모장을 열고 최소화 → 트레이 메뉴 "창 목록 로그" → 로그에 메모장이 없음 | |
| 클로킹 창 제외 | UWP 앱(예: 계산기)을 열었다 닫은 직후(백그라운드 클로킹 상태) "창 목록 로그" → 로그에 해당 창이 없음 | |
| Z-order·경계 | 창 두 개를 겹쳐 놓고 "창 목록 로그" → 위 창이 먼저, 경계가 그림자 제외한 실제 테두리와 일치 | |
| 관리자 권한 표시 | 관리자 권한으로 띄운 메모장이 elevated=true로 기록됨 | |
