# T60 — 설정 화면

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 단축키 변경 즉시 적용 | 트레이 "설정" → 단축키 칸 클릭 → Ctrl+Alt+F1 누름 → 적용 → 창 닫지 않고 Ctrl+Alt+F1로 켜짐, 옛 조합은 안 켜짐 | |
| 잘못된 핫키 저장 안 됨 | 수식 키 없이 A만 누름 → 빨간 안내, settings.json 변화 없음 | |
| 충돌 안내 | 다른 프로그램이 쓰는 조합(예: Win+E) 적용 → "다른 프로그램이 사용 중" 표시, 옛 조합 그대로 동작 | |
| 도구별 기본 색 즉시 반영 | 펜 색을 파랑으로 클릭 → 바로 켜서 그으면 파랑 | |
| 사라지는 시간 | 슬라이더 5초 → 사라지는 펜이 5초 유지 | |
| 저장 위치 | 찾아보기로 폴더 변경 → Ctrl+S 결과가 그 폴더에 저장 | |
| 시작 시 실행 | 체크 → `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ScreenAnnotation` 값 생성, 해제 → 삭제 | |
