# T12 — 모니터별 화면 캡처 확인

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| PNG 육안 확인 | 트레이 메뉴 "테스트 캡처" → `%TEMP%\ScreenAnnotation\capture_<DeviceName>.png` 저장 → 모니터별 1장, 내용이 실제 화면과 일치 (혼합 DPI 포함) | |
| 캡처 방식·소요 시간 | 로그에서 모니터별 방식(DXGI/GDI)과 ms, `CaptureAll(n) took …ms` 확인 (4K+FHD) | 2026-10-14 자동: DISPLAY1 2880x1800 DXGI 22~30ms, DISPLAY2 2560x1600 DXGI 9~40ms, 전체 23~43ms |
| DXGI 타임아웃 경로 | 화면을 바꾸지 않고 "테스트 캡처"를 연속 두 번 → 두 번째도 DXGI로 직전 프레임 반환 (로그) | |
