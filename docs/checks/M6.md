# M6 게이트 — 출시 (사용자 확인)

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 설치·제거 | dist-installer\ScreenAnnotation-Setup-*.exe 설치 → 실행 → 제거 → Program Files 잔여 파일 없음 | |
| 자동 시작 | 설정 → "윈도우 시작 시 실행" 켜고 재로그인 → 트레이에 떠 있음 | |
| 첫 실행 안내 | 첫 실행에 안내창, "다시 보지 않기" 후 재실행에 안 뜸 | |
| 설정 즉시 적용 | 단축키 변경·색·사라지는 시간·저장 위치 바꾸면 바로 반영 | |
| 화면 공유 | Zoom·Teams·OBS·Discord 전체 화면 공유에서 판서가 보임 | |
| 관리자 권한 창 | 관리자 앱 위에서 Ctrl+클릭 → 이미지 인식으로 사각형 | |
