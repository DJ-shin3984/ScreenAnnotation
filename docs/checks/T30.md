# T30 — Ctrl+휠 확대·화면 이동

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 확대 후 판서 위치 | Ctrl+휠로 8×까지 확대 → 점 찍기 → Ctrl+0 → 같은 화면 자리에 있음 (오차 1px) | |
| 커서 아래 고정 | 특정 글자 위에서 Ctrl+휠 → 그 글자가 커서 아래 그대로 | |
| 가장자리 제한 | 확대 상태에서 가운데 버튼 드래그로 끝까지 밀어도 검은 여백이 안 보임 | |
| Ctrl+0 | 어느 배율에서든 1×·원위치로 | |
| 이동 | 가운데 버튼 드래그, Space+좌클릭 드래그 둘 다 이동. 이동 중 획이 안 그어짐 | |
| 확대 중 굵기 | 8×에서 4px 펜으로 그린 획이 1×에서 0.5px(얇게) | |
| HUD·팔레트 | 확대해도 HUD·우클릭 팔레트·굵기 미리보기 크기는 그대로 | |
| 끄기 후 | 다시 켜면 1×부터 시작 | |
