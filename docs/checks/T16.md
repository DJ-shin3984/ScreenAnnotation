# T16 — 워치독 확인

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 동반 실행 | 앱 실행 → 작업 관리자에 `ScreenAnnotation.Watchdog.exe`가 함께 뜸 | |
| UI 정지 복구 | 트레이 숨은 디버그 메뉴 "UI 스레드 정지"(UI 스레드 `Thread.Sleep(10000)`) 실행 → 3초 이내 오버레이 창 숨김 + 앱 프로세스 종료 + 화면 조작 가능 | |
| 비활성 시 무시 | 오버레이가 꺼진 상태(Active=0)에서 "UI 스레드 정지" → 10초 뒤 앱이 그대로 살아 있음 | |
| 정상 종료 | 트레이 "종료" → Watchdog 프로세스도 함께 사라짐 | 2026-10-14 자동: 앱 종료 후 Watchdog 프로세스 없음 |
