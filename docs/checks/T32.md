# T32 — 멀티 모니터·혼합 DPI

설계상 이미 만족하는 항목: 획은 시작한 모니터의 OverlayWindow가 마우스를 캡처하므로 그 모니터에만 속한다. Tab·색·굵기(ToolState)는 전역 싱글턴이라 모든 모니터 공통. 확대(ViewTransform)는 창마다 따로. 핫키는 모든 모니터를 동시에 캡처·표시한다.

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 커서·획 위치 오차 2px 이내 | 4K 150% + FHD 100%에서 각 모니터에 그리기, 커서 끝과 획 시작점 비교 | |
| 모니터 경계 | 왼쪽 모니터에서 시작한 획을 오른쪽 모니터까지 끌기 → 경계에서 잘리고 오른쪽에는 안 그려짐 | |
| 배치 좌/우/위 | 디스플레이 설정에서 보조 모니터를 좌·우·위로 옮겨 각각 켜기 → 정지 화면이 실제와 일치 | |
| 상태 공유 | 한 모니터에서 Tab·색 변경 → 다른 모니터 HUD도 같은 값 | |
| 확대 독립 | 한 모니터만 Ctrl+휠 → 다른 모니터는 1× 유지 | |
