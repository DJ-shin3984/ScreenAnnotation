# T11 — 전역 핫키 확인

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 포그라운드 무관 수신 | 앱 실행 → 메모장을 포그라운드로 두고 Ctrl+Shift+Space → 로그(%LOCALAPPDATA%\ScreenAnnotation\logs)에 HotkeyPressed 기록 | 2026-10-14 자동(keybd_event): 켜기/끄기 2회 동작 |
| 등록 실패 알림 | 다른 프로그램(예: AutoHotkey `^+Space::return`)이 같은 조합을 먼저 등록한 상태에서 앱 실행 → 트레이 풍선 알림 "단축키 등록 실패" 표시, 앱은 종료되지 않음 | |
