# T40 — 요소 인식 통합·범위 확장

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 단어→줄→문단 확장 | Word·Chrome 문단 위에서 같은 자리 Ctrl+클릭 반복 → 선택 사각형이 단어→줄→문단→단어 | |
| 이미지→감싼 영역 | Chrome 이미지 Ctrl+클릭 반복 → 이미지→감싼 요소 | |
| 시간 상한 | 응답 없는 앱 위에서 Ctrl+클릭 → UI 멈춤 없음, 150ms 뒤 2차(이미지 분석)로 | |
| 2차 경로 | PDF 뷰어·이미지 뷰어에서 Ctrl+클릭 → 이미지 분석으로 사각형 | |
