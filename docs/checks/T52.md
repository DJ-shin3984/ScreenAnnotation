# T52 — OCR 서비스·영역 OCR

엔진은 Windows 내장(Windows.Media.Ocr)만 쓴다. ONNX 대체 모델 없음 (기획자 결정 2026-10-15).

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| PDF 뷰어 Ctrl+클릭 | PDF를 띄우고 켜기 → 글자 위 Ctrl+클릭 → 단어 사각형, 같은 자리 반복 Ctrl+클릭 → 줄 → 문단 | |
| 원격 화면 Ctrl+클릭 | 원격 데스크톱 창의 글자 위 Ctrl+클릭 → 인식 사각형 | |
| Ctrl+드래그 영역 → 클립보드 | 글자 영역을 Ctrl+드래그 → HUD "복사됨" → 메모장에 붙여넣기, 한·영 샘플 각 1회 | |
| 인식 중 판서 지연 없음 | 큰 영역 OCR 중 펜으로 긋기 → 끊김 없음 | |
| 언어팩 없을 때 | 한국어 OCR 언어팩 제거 후 실행 → 로그 경고 + Ctrl+드래그 시 HUD 안내 문구 | |
