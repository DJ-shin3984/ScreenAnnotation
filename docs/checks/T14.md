# T14 — 전체 화면 오버레이 창 확인

트레이 메뉴 "오버레이 테스트": 모든 모니터 캡처 → 오버레이 표시 → 2초 뒤 숨김.

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 혼합 DPI 정합 | 4K 150% + FHD 100% 구성에서 "오버레이 테스트" → 정지 화면이 실제 화면과 어긋나지 않음 (창 테두리·글자 위치 육안 비교) | |
| 작업 표시줄 | 오버레이가 작업 표시줄 위까지 덮음 | |
| Alt+Tab | 오버레이 표시 중 Alt+Tab 목록에 오버레이가 보이지 않음 | |
| 숨김 후 복귀 | 2초 뒤 오버레이가 사라지고 이전 창이 그대로 보임 | |
