# M2 게이트 — 판서 엔진 (사용자 확인)

통과 기준: 연속 판서 입력→표시 P95 16ms(4K), 휠·Tab 반응 즉시(다음 프레임), 1분 연속 판서 끊김 없음.

## 1. 입력→표시 지연

절차: 켠 뒤 1분간 빠르게 연속 판서 → 로그의 `L3 frame` 통계(또는 HUD 디버그) P95.

## 2. 키·마우스 체크리스트

| 입력 | 기대 동작 | 결과 |
| --- | --- | --- |
| 좌클릭 드래그 (펜) | 빨간 획, 빠르게 원을 그려도 각지지 않음 | |
| Tab | 펜 → 형광펜 → 도형 → 펜, HUD 즉시 반영 | |
| Shift+Tab (펜) | 일반 → 사라지는 → 레이저 | |
| Shift+Tab (형광펜) | 자유 → 직선 (수평 ±10° 자동 수평) | |
| Shift+Tab (도형) | 사각형 → 삼각형 → 원 → 원기둥 → 화살표 → 직선 | |
| 형광펜 겹쳐 긋기 | 같은 획 안에서 진해지지 않음 | |
| 사라지는 펜 | 손 뗀 뒤 2.5초 유지 → 0.5초 페이드, 연속 획은 함께 사라짐 | |
| 레이저 | 획 없음, 빛나는 점 + 0.3초 꼬리 | |
| 도형 + Shift | 정사각형·정원·정삼각형·45° 스냅 | |
| 휠 | 굵기 한 칸씩, 커서에 굵기 원 0.8초 | |
| 우클릭 (펜) | 9색 원형 팔레트, 끌어서 선택 / 짧게 클릭 후 선택 둘 다 | |
| 우클릭 (도형) | 도형 6종 팔레트 | |
| 우클릭 모니터 가장자리 | 팔레트가 화면 안에 들어옴 | |
| 1~9 | 색 바로 선택, 도구별 기억(펜 빨강·형광펜 노랑) | |
| E | 지우개 켜기/끄기(직전 도구로), 겹친 객체 중 닿은 것만 삭제 | |
| 지우개 드래그 1회 → Ctrl+Z | 한 번에 전부 복원 | |
| Ctrl+Z / Ctrl+Y | Undo/Redo | |
| Esc | 진행 중 취소, 팔레트 닫힘, 펜/일반으로. 앱은 안 꺼짐 | |
| HUD | 우측 하단에 도구·변형·굵기·색 | |
