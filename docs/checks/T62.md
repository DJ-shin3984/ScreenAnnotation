## 기타

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 관리자 권한 창 | 관리자 메모장 위에서 켜기 → 판서 됨, Ctrl+클릭은 이미지 분석 경로(글자 없음) | |
| 전체 화면 게임 | 독점 전체 화면 게임 위에서 켜기 → 지원 대상 외임을 확인, 앱은 죽지 않음 | |
| 혼합 DPI | 4K 150% + FHD 100% 에서 정지 화면 정합 | |
| 가이드 | GUIDE.md 내용이 현재 동작과 일치 | |
