# T31 — 텍스트 입력창 (한글 IME) 확인

완료 조건: 한글 조합 중 Enter·Esc·Tab·클릭 시 글자 누락·중복 0건, 재편집 Undo 가능.

## 한글 조합 시나리오 (켠 뒤 T 키 → 입력창)

| # | 절차 | 기대 | 결과 |
| --- | --- | --- | --- |
| 1 | "한글" 입력 후 Ctrl+Enter | "한글" 확정, 펜으로 복귀 | |
| 2 | "한" 조합 중(ㅎ+ㅏ+ㄴ, 아직 미확정) Ctrl+Enter | "한" 누락·중복 없음 | |
| 3 | "한" 조합 중 Esc | 내용이 있으므로 확정, "한" 그대로 | |
| 4 | 빈 입력창에서 Esc | 입력창만 사라짐, 저장 없음 | |
| 5 | "가나" 조합 중 Tab | 도구가 바뀌지 않고 입력창 유지 | |
| 6 | "다" 조합 중 입력창 밖 클릭 | "다" 확정, 클릭은 그리기로 이어지지 않음 | |
| 7 | "라마" 입력 → Enter → "바사" → Ctrl+Enter | 두 줄 텍스트 | |
| 8 | 영문 "abc" 뒤에 한글 "한" 조합 중 Ctrl+Enter | "abc한" | |
| 9 | 입력 중 휠·숫자 키 | 입력창에만 전달, 굵기·색 안 바뀜 | |
| 10 | 굵기를 바꾼 뒤 T | 글자 크기가 굵기 단계에 비례 | |

## 재편집

| 절차 | 기대 | 결과 |
| --- | --- | --- |
| 기존 텍스트 더블클릭 → 글자 수정 → Ctrl+Enter | 같은 위치에 수정된 글자 | |
| Ctrl+Z | 수정 전 글자로 복원 | |
| Ctrl+Y | 다시 수정된 글자 | |
| 더블클릭 후 글자를 모두 지우고 Esc | 원본 유지 | |
