# T42 — 선택·이동·복제·텍스트 복사

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| 8방향 핸들 | 선택 시 핸들 8개, 모서리 드래그 → 비율 유지 크기 조절 | |
| 이동 Undo | 드래그 이동 → Ctrl+Z 한 번에 원위치 | |
| Alt+드래그 복제 | 원본 자리 메움 없이 복제본이 따라옴 | |
| Delete | 선택 요소 삭제, 원래 자리 메움만 남음 | |
| 텍스트 Ctrl+C | 텍스트 요소 선택 → Ctrl+C → 메모장에 글자 붙여넣기 | |
| 이미지 Ctrl+C | 이미지 요소 → Ctrl+C → 그림판 붙여넣기 | |
| 선택 해제 | 빈 곳 클릭 / Esc | |
