# T50 — 합성 PNG 저장·복사

| 항목 | 절차 | 결과 |
| --- | --- | --- |
| Ctrl+S 저장 | 판서 후 Ctrl+S → 사진\ScreenAnnotation\yyyyMMdd_HHmmss_N.png (모니터별 1장) | |
| 화면과 동일 | 저장 이미지를 열어 켜져 있던 화면·판서와 같은지 확인. 4× 확대 상태에서 저장해도 1× 원본 크기 | |
| 사라지는 펜 포함 | 사라지는 펜 획이 보이는 동안 Ctrl+S → 이미지에 포함 | |
| Ctrl+C 복사 | 커서가 있는 모니터 합성본 → 그림판에 붙여넣기 | |
| HUD 표시 | 저장·복사 후 우측 하단 HUD에 "저장됨" 1초 | |
| 4K 성능 | 4K 모니터에서 Ctrl+S → 로그 `Export took` 500ms 이내 | |
